## 1. 피해 계산

### 기본 공식 `[커뮤니티 검증]`
```
최종 타격 = 스킬 계수% × 피해(Damage) 스탯 × (1 + 원소 피해%) × (1 + 계열 피해%) × [별도 곱연산]
```
- 예시: 계수 70% 화염 주문 · 피해 6000 · 화염 +125% · 주문 계열 +10% → `0.7 × 6000 × 2.25 × 1.1 = 10,395`
- **같은 종류의 %는 합연산**(원소끼리, 계열끼리), **다른 종류끼리는 곱연산**
- 장비의 "가해 피해 % 증가"(generic increased damage)는 모든 계산 후 곱해지는 **별도 최종 곱연산**

### 제압 (Overpower) — 저항 관통 `[위키]`
```
최종저항 = 적저항 − 적저항 × (제압 / 100)
```
- 예: 제압 50% vs 적 저항 40% → 20%
- 직접 피해에만 적용. 정확한 상한값 `[미확인]` (빌드들은 90~100%를 목표로 함)

### 에테르 피해 (Ethereal)
- 적의 **모든 저항을 무시**하고, 내 **최고 원소 피해 스탯**의 혜택을 받음
- 출혈은 에테르 취급이라 원소 스탯을 받지 않음

### 기본 공격 (Base Skill) `[데이터]`
- 랭크별 **100 / 110 / 120 / 130 / 140%** (0.710에서 140~180%에서 하향)
- **마나 소모 없음** + **사용 시 마나 4% 회복** (0.900)
- 클래스마다 2종씩, 총 8종. 기본 공격 슬롯을 대체하므로 둘을 동시에 들 이유 없음

## 2. 지속 피해 (DoT)

- 도트는 **초당 피해 기반** — 틱 속도는 연출이고 **공격 속도의 영향을 받지 않음** `[개발자]`
- 적중 시 도트는 **발동한 타격의 스냅샷**: 100 타격 + 60% 출혈 = 초당 60. 스킬이 강해지면 도트도 강해짐
- **직접 타격만 온힛 효과·패시브를 발동**시킴. 도트 틱은 아무것도 발동 못 함
- **1.54부터** 도트를 걸면 몇 프레임 안에 첫 틱이 들어옴 (기존엔 1초 대기) `[데이터]`
- 도트의 치명타는 별도 고정 확률을 쓴다는 개발자 발언(구버전) → 도트 빌드에 치명타가 무의미한 근거 `[미확인 - 1.5x 현재]`
- 장비 도트 스탯 귀속: 연소=화염, 독 도트=독, 냉각=냉기. **출혈만 에테르**

## 3. 방어

- **회피·피해 감소는 곱연산** (8%+8%+8% = 24%가 아니라 22%) `[게임 내 도움말]`
- **저항 상한 80%**. 높은 난이도는 기본 저항을 마이너스로 깎으므로 표기상 **130% 오버캡**이 목표
- **간접 피해는 한 번에 최대 체력의 5%가 상한** — 도트·장판은 즉사 불가. **즉사는 직접 타격만** `[개발자]`
- 간접 피해는 저항·배리어를 관통하고 아무것도 발동시키지 못함
- **기절은 쿨다운까지 정지**시킴. 방해(Interrupt)는 쿨을 최대로 되돌림
- 막기(Block)는 방패 전용 → 워록·워든에는 해당 없음
- 스태거: 받은 피해 일부를 3초에 걸쳐 분산, **곱연산으로 스케일**
- 워록·워든은 클래스 기본으로 **전 저항 +10%** `[데이터]`

## 4. 공격 속도 · 프레임

- 게임 로직 **60FPS 고정**. 모든 스킬 기본 모션 0.5초(30프레임)
- 공속 %가 모션을 줄이며 **정수 프레임 브레이크포인트**로 끊김
- 확인된 예: 268%(격노 인챈트 포함) = 8프레임 / 340% = 9프레임(다른 스킬)
- 공속은 소환수에 적용되지만 **도트 틱·오라·고정 보석 피해에는 무효**
- 전체 프레임 표는 `[미확인]`

## 5. 킬 연계 (Killstreak)

- 끊김 없는 연속 처치가 **보너스 경험치·크리스탈** 지급. 난이도가 높을수록 증가
- **피해 버프는 없음**
- 도트·연쇄 빌드는 화면 밖 처치로도 게이지가 유지돼 맵 전체가 한 번의 스트릭이 됨

## 6. 소환수 (동료)

```
소환수 피해 = 계수% × 내 피해 스탯 × 원소% × 동료 피해%
```
- **동료 피해 / 동료 체력** 스탯이 곱해짐 `[개발자]`
- 소환수는 플레이어의 치명타 확률·이동 속도를 상속하나 **제압은 상속하지 않음** `[커뮤니티, 개발자 미확인]`
- **1.53부터 소환수는 항상 스킬을 최대 랭크로 사용** `[데이터]`

## 11. 아이템 · 제작

### 등급
일반 → 마법부여 → 희귀 → 고유 → 전설 → **진전설(True Legendary)**
- 진전설은 **100레벨 + 전설 난이도 이상 드랍 전용**, **도박 불가**
- 세트: 유니크 등급 세트는 **10레벨**부터, **전설 클래스 세트는 30레벨**부터 `[데이터: help/4.txt]`

### 변환 (테오)
- **세트 아이템 변환**: 챔피언의 왕관 30 + 세트템 → 같은 세트 다른 부위
- 전설 3 → 무작위 전설 (같은 부위 3개면 그 부위 확정) / 진전설 5 → 무작위 진전설
- **전설 강화**: 전설 + 같은 부위 진전설 + 왕관 20 → 진전설급 기본 스탯
- 프리즈매틱 소켓(큐브/구체/별) 각 왕관 30, 아이템당 1개 영구
- **신화 무기 제작**(야수 DLC · 헬포지): 세트 무기 + 대형 보스 재료 → **룬 소켓 2개**

### 마법부여 (샹텔)
- 스크램블(전체 리롤) / 리롤(한 옵션) / **강화**(수치 상승 — 해당 옵션 잠금)
- 진한 주황 = 아이템 파워, 연주황(Solid) = 제거 불가
- 상급 강화는 틴카의 영역에서 **기억 정수** 소모
- **원소 % 피해는 인챈트로 붙일 수 없음** — 아이템이 원래 갖고 나오는 옵션 `[커뮤니티 DB 검증]`

| 이동 속도 | **장화** · 장신구 · 반지 · 목걸이 |
| 체력 | 투구 · 갑옷 · 무기 · 장화 · 장신구 · 반지 · 목걸이 |
| 적중 시 체력 | 무기 · 장화 · 목걸이 · 보조장비 |
| 저항 | 투구 · 갑옷 · 장화 · 반지 · 목걸이 · 보조장비 (**무기 불가**) |
| 경험치 +% (최대 50%) | 투구 · 무기 · 장신구 · 반지 · 목걸이 · 마도서 (**갑옷·장화 불가**) |

- 반지·목걸이는 **에픽 옵션이 확정 1개**

### 룬
- **하급 룬**: 전설·희귀 파워 추출, 또는 던전 아노말리 보스 직드랍
- **상급 룬**: 진전설 파워 추출. 착용 **최대 3개** (「위대함」 룬으로 4개)
- 제작: 파워 있는 아이템 + 룬스톤 + 챔피언의 왕관 50 (테오)
- 아이템당 룬 1개, 같은 이름 중첩 불가

### 보석 (젬마)
- 7종 원소 × **큐브 · 구체 · 별** 3형태 × 3부위군 = 63효과, 3품질
- **별이 가장 강력** (무기·보조 우선)
- 동일 보석 3개 → 상위 등급 합성
- 원소 대응: 시트린=화염, 카이아나이트=냉기, 라리마=번개, 크리소베릴=독, 헤마타이트=물리/출혈, 차로아이트=암흑
- 워록 전용 효과: 헤마타이트 별(방어구)=영혼 지속, 차로아이트 별(장신구)=영혼 강탈 확률

### 영약 · 물약
- **1.40에서 영약 전면 개편** — 몹이 드랍하지 않고 **틴카의 영역·크로니콘의 영약 상점 구매**. 구 영약은 더 이상 안 나옴 `[데이터]`
- 등급별 2개씩 동시 적용
- **인젝터·런처**는 **50레벨 + 영웅 난이도 이상**에서만 드랍 `[데이터: 1.50]`
- 물약은 **10초 쿨**, 절반만 즉시 회복(나머지 5초에 걸쳐)
- 1.54 신규 **초월(Transcendent) 물약** 4종 — 100레벨 몹 드랍 또는 사렉 구매

## 12. 루팅 필터 `[데이터: locale/EN/menu FILTER OPTIONS]`

**두 벌로 나뉨**
1. **표시 필터** — 바닥에 보여줄 것
2. **방사형 루팅**(Radial Loot · 기본 Q) — 그 키로 주워올 것

조절 항목:
- 등급 토글: 일반·마법부여·희귀·고유·전설·진정한 전설 (표시/방사형 각각)
- 소모품: 물약·영약·두루마리·열쇠·기타 소모품
- 다른 클래스 아이템 필터링
- 게임 세계에서 품질 필터링된 장비 제거 (되돌릴 수 없음)
- 방사형 루팅으로 장비를 줍지 않음 (Q를 소모품 전용으로)
- 방사형 루팅 키로 자동 루팅 전환 (Q를 토글로)
- 프로필 복수 생성 가능

- 능력치 **획득 반경**이 방사형 루팅 사거리도 늘림 `[데이터: help/9.txt]`
- **주의**: 필터로 숨겨도 드랍 자체는 발생 → 지식의 연대기 스택 유지 조건은 **마법 발견 0%**

## 13. 사망 · 모드

## 14. 캠페인

- 5막 구성. 완주 시 레벨 **60~80**, **틴카의 영역**이 계정 전체에 개방
- 막 보스: 1막 대여사제 메델라 / 2막 대드루이드 오크스톰 / 3막 매독 / 4막 에지마 / 5막 아래의 야수
- 3막에 **바닥 버튼을 눌러야 진행되는 구간**이 있음 (버그 아님)
- 보스는 같은 난이도의 챔피언보다 쉬움. 보스방 전에 구역 정리로 **신단 버프** 확보 권장
- 1.54: **신전 상부 회랑 제단에 동전 헌납** 시 유용한 아이템 확률 크게 상승

## 15. 정예 · 챔피언

- **정예**(왕관 1개): 강화된 일반 몹, **무리로** 등장
- **챔피언**(왕관 3개): **단독** 등장, 체력 훨씬 많고 접두 다수, 길찾기 우수(놓치지 않음), 기본 10% 저항
- 높은 층에서 진짜 위협은 보스가 아니라 챔피언

**캐스터를 죽이는 접두**: `Warp`(순간이동) · `Grappler`(1.5초 80% 감속) · `Fast` · **`Explosive`**(최대 체력 비례 사망 폭발 — 캐스터 즉사 1위) · `Static`(사망 시 번개) · `Sorcerer`·`Embershot`(원거리) · `Vampiric`+`Regenerative` · `Stoneskin`·`Resistance`(제압 필요) · `Summoner`

**속성 접두**(`Frozen`·`Poisoned`·`Static`·`Plagued`·`Infernal`)는 몹의 물리 공격을 그 속성으로 **변환** → 한 저항만 올리면 안 되는 이유
