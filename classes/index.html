클래스

크로니콘의 플레이 가능한 클래스 5종과 각 클래스 문서로 가는 입구입니다.

검색 결과가 없습니다.

5종 비교

본편에 4종, DLC로 1종이 추가됩니다. 아래 수치와 특징은 게임 내 클래스 선택 화면 원문 locale/menu class_*에서 확인한 것입니다. 데이터

클래스주력 원소자원특징기본 보너스
템플러
Templar		 신성화염물리번개 마나 방패로 공격을 차단하고, 치유·방어 수단이 가장 다양합니다 피해 감소 +30%
버서커
Berserker		 화염번개물리냉기 마나 + 분노 일부 능력에 분노를 소모합니다. 기본 체력·마나 재생이 2배 피해 감소 +30%

워록

메카니스트

메카니스트는 별도 DLC가 필요합니다. 본편만 가지고 있으면 클래스 선택 화면에 잠긴 상태로 표시됩니다. 나머지 4종은 본편에 포함돼 있습니다.
참고로 고대 야수 Ancient Beasts DLC는 클래스를 추가하지 않고 아티팩트·원정 트리를 여는 별개의 확장입니다. 엔드게임 빌드 상당수가 이쪽을 전제로 합니다.

클래스마다 공통인 것

클래스가 달라도 스킬 시스템의 골격은 같습니다. 데이터

  • 클래스마다 스킬 트리 4종. 트리마다 실제 스킬 열이 8개이고, 해금 기준은 세로줄이 아니라 가로 열입니다
  • 확정 해금 레벨은 1열 = 1, 2열 = 5, 3열 = 10, 8열(궁극기) = 40
  • 최대 랭크는 액티브 5 · 대부분의 패시브 3 · 궁극기 1
  • 스킬 포인트는 레벨당 1개, 100레벨에 총 100개이고 네 트리에 자유 배분합니다 (Ctrl + 클릭 = 5포인트씩)
  • 궁극기는 하나만 장착 가능하고, 8종 전부 쿨다운 60초입니다
  • 액티브 슬롯 6개 + 벨트 슬롯 4개. 한 버튼에 여러 스킬을 겹쳐 놓으면 슬롯 순서상 오른쪽 → 왼쪽으로 발동합니다
  • 의식 Ritual 스킬은 슬롯에 넣어두기만 해도 패시브 절반이 작동합니다
  • 마스터리는 100레벨 전부터 쌓입니다. 클래스 트리 4줄 + 공용(왕관) 줄 3개 구성이고 상한이 없습니다
영혼 관련 마스터리 노드(영혼 관리자·영혼 감옥)는 워록 전용이 아니라 공용 줄 소속입니다. 한편 워록 스킬 트리의 「최대 영혼 +5」 노드는 2019년 0.90.0에서 삭제됐습니다 — 그걸 언급하는 조언은 죽은 정보입니다.

클래스 문서

현재 워록과 템플러가 작성돼 있습니다. 나머지 세 클래스는 원자료(Rahlence 가이드 PDF)까지 수집을 마쳤고 문서 작성만 남았습니다.

워록 Warlock

영혼 · 저주 · 소환. 레벨링부터 T1000+ 푸시 빌드까지 작성 완료

템플러 Templar

방패로 막고 태우는 근접. 전쟁신 세트 · 번개 시너지 · 개요·레벨링·성장 작성 완료

버서커 Berserker

분노 자원, 근접 화력 · 원자료 수집 완료 (Rahlence 레벨링·성장 PDF)

워든 Warden

자연 소환, 회피 · 원자료 수집 완료 (Rahlence 레벨링·성장 PDF)

메카니스트 Mechanist

예정 — 탄약 자원, 포탑·드론. 별도 DLC 필요

템플러 하위 문서

  • 템플러 개요 — 트리 4종(복수·격노·신념·구원) · 타오르는 확신 · 번개 시너지
  • 레벨링 1 → 100 — Lv10 장비 8종 · Lv45 전쟁신 세트 · 구간별 트리 배분
  • 성장 (100레벨 이후) — 엔드게임 장비 8종 · 룬 조합 · 완성 트리 · 아티팩트

워록 하위 문서

  • 워록 개요 — 트리 4종(부패자·리치·악마학자·수확자)과 자원
  • 레벨링 1 → 100 — 해골 연타, 30레벨 모독자 세트, 도박·염료 파밍
  • 성장 (100레벨 이후) — 목적 있는 파밍, 인챈트 순서, 원정 트리
  • 엔드게임 빌드 5종 — 저주 모독자 · 메테오라 · 데몬 로드 · 태양과 달 화염 태풍

이 위키의 범위

이 위키는 워록 문서에서 출발했지만 클래스별로 확장할 수 있는 구조로 짜여 있습니다. 문서는 classes/<클래스>/ 아래에 개요 · 레벨링 · 성장 · 빌드 4종 세트로 놓이고, 클래스와 무관한 계산식·아이템·난이도 규칙은 게임 기초 쪽에 한 번만 적습니다.

  • 새 클래스를 추가할 때는 이 페이지의 .tile.soon에서 soon을 떼고 실제 경로를 넣으면 됩니다
  • 왼쪽 목차도 같은 방식입니다 — class="soon"과 href="#"만 교체합니다
  • 클래스 문서에서 반복될 만한 설명(피해 계산·저항·룬·보석)은 게임 기초로 빼고 링크하는 것을 원칙으로 합니다
수록 기준은 공식 디스코드 #build-forum에 실제로 올라온 자료입니다. 근거 등급은 데이터(게임 파일 대조) · 개발자 · 커뮤니티 · 미검증으로 표기합니다.
