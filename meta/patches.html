패치 동향

플레이에 영향을 주는 변경만 골라 정리했습니다. 오래된 가이드를 읽을 때 무엇이 이미 바뀌었는지 확인하는 용도입니다.

검색 결과가 없습니다.

현재 상황

라이브 버전 1.54.1 (2025-11-24). 이후 정식 패치 없음. 데이터
개발자 공지: 다음은 엔드게임 DLC이며 그때까지 소소한 버그 수정 외 업데이트가 없습니다. 목표 시점은 2026년 중반. 개발자
개발 공백이 있었습니다. 1.52.0(2023-03)은 제목이 "The Final Update"였고, 2.5년 뒤 1.53.0(2025-08)에서 개발이 재개됐습니다. 2023년 3월 ~ 2025년 8월 사이에 쓰인 글은 "게임이 끝났다"는 전제로 작성된 것이라, 이후 추가된 기능(자동 시전 등)을 모릅니다.

1.54.0 · 1.54.1 — Isolation & Anomalies (2025-11)

레벨링에 직접 영향

  • 초반 전리품 하향 개발자 — 레벨이 오르며 점차 예전 수준으로 회복되도록 재조정. 100레벨 전리품은 그대로. 낮은 레벨·낮은 난이도에서 마법부여·희귀가 덜 나오고 가방이 더 자주 나옵니다. 개발자 설명은 "초반 루팅 경험이 덜 부담스럽도록"
  • 버그 수정: 에픽·마법부여가 의도보다 10배 높은 확률로 나오고 있었고, 그 탓에 일반(흰색) 등급이 드랍 풀에서 사라져 있었습니다
  • 신전 상부 회랑 제단에 동전 헌납 시 쓸 만한 아이템이 나올 확률 대폭 상승
  • 예전 가이드의 "20레벨이면 희귀템이 넘친다"는 서술은 이제 틀립니다

전투

  • 지속 피해(도트)를 걸면 몇 프레임 안에 첫 틱이 들어옵니다 (기존엔 1초 대기). 도트 위주 빌드에 직접적인 상향 데이터

아노말리

  • 타일셋·레이아웃 조합 60 → 92. 새 Wormgut 타일셋(4막 최종 보스 기반), 막다른 길 없는 긴 복도 레이아웃, 나선형, 대형 개활지 추가. Bone Pits 레이아웃은 제거(타일셋은 유지) → 생성 방식 설명

모드 · 아이템

  • 고립(Isolation) 모드 신규 — 공용 창고·재화·글로벌 진행까지 완전 분리. 멀티 불가, 해제 불가, 하드코어와 병행 가능
  • 초월(Transcendent) 물약 4종 — 100레벨 몹 드랍 또는 사렉 구매
  • 워록 타락의 로브 강화치 4/5%로 하향 (기존 5/8%) — 재생형 역병 마법사 빌드에 영향
  • 요툰헬름 강화 상한 50/100%로 상향 (기존 30/60%)

1.53.0 — 개발 재개 (2025-08)

  • 자동 시전(Auto Cast) 추가 개발자 — 스킬 바인드 메뉴에서 「Auto」 체크. 해당 키가 자동 시전 토글이 됩니다. 예전의 키바인드 꼼수나 "이 아이템이 대신 시전해준다"는 팁의 가치가 크게 줄었습니다
  • 소환수가 항상 스킬을 최대 랭크로 사용 — 소환 빌드 상향
  • 무한 아노말리가 포탈을 두 개 제공 (다음 층 / 같은 층 반복)
  • 워록 비명 해골 지팡이: 튕김을 다 못 채우면 남은 피해의 50%를 주도록 보완

1.50 · 1.52 (2022–2023)

  • 인젝터·런처는 50레벨 + 영웅 난이도 이상에서만 드랍 데이터
  • 아이템이 다른 클래스 전용 옵션을 굴리지 않게 됨 — 장비 맞추기가 빨라짐
  • 워록 피학주의자 약화 중첩이 곱연산으로 변경(하향), 뼈 스킬 상호작용 수정(상향)

1.40 — 엘릭서 체계 전면 개편 (2022-06)

1.40 이전 글의 엘릭서 조언은 전부 무효입니다. 엘릭서은 더 이상 몹에서 드랍되지 않고 틴카의 영역·크로니콘의 엘릭서 상점에서 구매합니다. 구 엘릭서은 레거시로 분류돼 나오지 않습니다. 데이터
  • 엘릭서 27종 추가, 3등급 · 등급별 2개씩 동시 적용
  • 인젝터·런처 도입 (벨트 장착형 유물) — MK1은 상점, MK2·MK3은 희귀 드랍, MK4·MK5는 숨은 변환 레시피
  • 타로에서 주문서 도박 불가로 변경 — 별도 주문서 상점 신설
  • 워록 관통의 비술 제단 의식 리워크 — 냉기 창 스킬에 광역을 더하는 대신 기본 피해를 곱연산으로 증폭. 「냉기 창 스킬」 태그 신설. 사신 3피스가 골격 파열 상시 발동으로 변경

테스트 빌드 테스트빌드

아래는 공식 디스코드 #tinka-notes에 올라온 테스트 빌드 내용입니다. 정식 출시본(1.54.1)에는 들어 있지 않습니다. 다음 정식 패치나 DLC에 포함될 수 있으나 확정이 아닙니다.

2026-06-25 빌드

  • 워록 사령 소환 비술 의식: 최대 랭크 초과 1랭크당 스켈레톤 +1 (기존엔 항상 5로 고정)
  • 워록 죽음의 군주 데스나이트가 파멸 스킬 쿨감을 표기(25%)와 달리 20%만 주던 버그 수정
  • 모든 유틸리티·궁극기 스킬이 최대 랭크 초과분을 제대로 반영하도록 수정
  • 버프를 거는 스킬 대부분에 「버프」 태그 추가
  • 적 접두 4종 추가: Geyser · Tentacles · Water Nova · Satellites
  • 단독 등장 계열 챔피언이 자기 복제 대신 약한 몹을 소환하도록 변경
  • 동료가 장비 교체 등으로 해산될 때 사망 폭발이 발동하지 않도록 수정
  • 고대 야수가 거리에 따라 이동 속도를 조절 — 순간이동을 자주 써도 따라옴
  • 던전 아노말리 보스 보상 상자가 항상 보스 자리에 생성
  • 여러 개활지 레이아웃의 몹 밀도 상향
  • 변환·스킬 재바인드 시 캐릭터를 새로고침해 스냅샷 악용 차단
